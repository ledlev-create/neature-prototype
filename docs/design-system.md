# Design System — Neature

Ce document sert de pont entre le prototype codé et l'intégration WordPress / Uncode.

## 1. Couleurs

### Brand
`#00265C`

Usage :
- titres
- navigation
- footer
- éléments structurants

### Accent
`#2D9DE3`

Usage :
- boutons principaux
- liens
- éléments actifs
- badges
- accents graphiques

### Nature
`#7DAF58`

Usage :
- éléments liés à l'environnement
- variantes de cartes
- accent secondaire

### Surface soft
`#EAF6FD`

Usage :
- fonds de sections
- badges
- arrière-plans de composants

---

## 2. Typographie

À compléter lorsque les polices définitives seront identifiées.

- H1 : `--font-size-h1`
- H2 : `--font-size-h2`
- H3 : `--font-size-h3`
- Corps : `--font-size-body`

---

## 3. Espacements

- XS : 8px
- SM : 16px
- MD : 24px
- LG : 40px
- XL : 64px
- XXL : 96px

---

## 4. Rayons

- Petit : 8px
- Moyen / cartes : 12px
- Grand : 22px

## 5. Composants

### Button
Variantes :

- Outline

### Solution Card
Variantes :
- Blue
- Green

### Section Title
Contient :
- eyebrow
- heading

### Header
Desktop + variante mobile à compléter.

### Hero
Contient :

## 6. Traduction future dans WordPress / Uncode

Le prototype doit servir de référence pour :

- couleurs globales
- typographies globales
- largeur de conteneur
- padding des sections
- styles de boutons
- styles de cartes
- responsive
- blocs / content blocks réutilisables
